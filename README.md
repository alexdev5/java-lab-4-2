# Лабораторна робота №4 (Варіант 2)
## Мета: 
Реалізувати із застосування узагальненого програмування ієрархію Java-класів для вольєрів з різними видами тварин

## Опис
У даній лабораторній роботі реалізовано програмну модель зоопарку.  
Програма дозволяє працювати з різними видами тварин та вольєрів, забезпечує коректне розміщення тварин відповідно до їх типу, а також підтримує обробку помилкових ситуацій.

## Можливості програми
- створення тварин різних видів
- розміщення тварин у відповідних вольєрах
- обмеження кількості тварин у вольєрі
- підрахунок загальної кількості тварин у зоопарку
- збереження та завантаження даних з файлу
- перевірка коректності роботи за допомогою тестів

## Примітка
Програма розроблена в навчальних цілях як виконання лабораторної роботи.
